# Agentic AI Connect Workshop

Welcome to the code repository for the **Agentic AI Connect** workshop, hosted by **GDG on Campus JIS University** and **Machine Learning Kolkata**!

Step into the next generation of Artificial Intelligence. This full-day, hands-on workshop is designed to help you build practical agentic AI workflows, moving beyond basic prompting.

## Event Details

- **Date & Time**: Saturday, August 8, 2026 | 10:30 AM – 4:30 PM IST
- **Venue**: JIS University, Agarpara, Kolkata, West Bengal
- **Entry**: Free (Mandatory prior registration & selection)

## What We Will Cover

- **Model Context Protocol (MCP)**: Build custom tools and connect AI models with external APIs, tools, and data.
- **Agent-to-Agent Communication**: Learn agent cards, task delegation, and messaging between agents.
- **Agentic Retrieval-Augmented Generation (RAG)**: Combine semantic search, tools, and agent decision-making for retrieval-based AI systems.
- **Full-Stack Agent Orchestration**: Bring MCP, RAG, and multi-agent workflows together in a practical application.

## Prerequisites

- Working knowledge of Python
- Basic Git/GitHub familiarity
- A laptop with Python and VS Code/Cursor installed

## Setup Instructions

1. **Clone the repository:**
   ```bash
   git clone https://github.com/sea-deep/agentic-ai-connect-workshop.git
   cd agentic-ai-connect-workshop
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Configure Environment:**
   Create a `.env` file in the root directory and add your OpenRouter API key:
   ```env
   OPENROUTER_API_KEY=your_api_key_here
   ```
   *(Get a free key at [openrouter.ai/keys](https://openrouter.ai/keys))*

## Running the Code

Run the demonstration script to see the agent in action:

```bash
python main.py
```
